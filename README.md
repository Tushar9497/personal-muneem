# ResumePro1 / Personal-Muneem

This repository contains a full-stack personal finance tracker called `Personal-Muneem`.

The app lets users:

- add income entries
- add expense entries
- view totals and current balance
- inspect recent transaction history
- visualize finances in the dashboard
